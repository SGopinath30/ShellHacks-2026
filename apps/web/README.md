# Synchro frontend

Synchro is a Next.js utility coordination dashboard connected to the public Gridlock API at https://gridlock-api-production.up.railway.app/api/v1. No API key, environment variable, local backend, or database setup is needed for these read-only requests.

From the repository root:

```powershell
npm --prefix apps/web install
npm --prefix apps/web run dev
```

Open http://localhost:3000. Node.js 20.9 or newer is required.

```powershell
npm --prefix apps/web run lint
npm --prefix apps/web run typecheck
npm --prefix apps/web test
npm --prefix apps/web run build
npm --prefix apps/web run test:browser
```

Browser tests use an installed Google Chrome and start a production server after a build. They mock the public API and cover the 3D scene, controls, timeline, ranking, encoded detail URLs, stale response protection, errors/retries, empty data, and responsive layout. Unit tests cover geographic edge cases, schedule handling, and evidence rendering. Screenshots go to the ignored `test-results/` directory. The test server uses port 3100 by default; set `PLAYWRIGHT_PORT` to override it. Schedule edge-case markup generated by the browser-test preparation script is ignored in `.test-fixtures/`.

## Live API integration

`lib/live-api.ts` fetches `/projects`, `/projects/geojson`, and `/opportunities` together. Selecting a match fetches `/opportunities/{encoded pair_id}`. Requests have a 20-second timeout and cancellation on selection changes/unmount. Loading, retry, and empty states are explicit; a failed request never falls back to synthetic data. The deployed API returned empty project and opportunity arrays when this integration was implemented.

The adapter accepts the supplied v1 project contract and opportunity records with `pair_id`, `distance.meters`, `tier`, and two projects (`projects` array or `project_a`/`project_b`, records or IDs). The public OpenAPI specification does not define opportunity response bodies, and nonempty production responses were unavailable for verification. A mismatched response shows an explicit error rather than inventing values. The opportunity endpoint's default page is displayed; pagination beyond that page is not implemented.

API ranking is preserved through utility/distance filtering. Meters are converted to miles for the existing UI; distances and tiers are never replaced by fixture matching rules. The distance slider expands to include the returned results. Exact construction bounds feed the timeline; uncertain bounds remain labeled and in-service dates stay milestones. Construction overlap is computed only for timeline display, not eligibility or ranking. The timeline range follows the supplied dates.

The existing interactive Three.js scene renders GeoJSON Point and LineString geometry from the map endpoint. Utility A stays blue and Utility B orange. Dashed links identify matched pairs and are explicitly not measured routes or evidence of shared infrastructure. The scene uses a local longitude-aware projection fitted to the compared projects; displayed distances come from the API. Building footprints, roads, and service territories are not provided by these endpoints, so their controls remain visible but unavailable for live data. Missing geometry stays unmapped and is disclosed. All project records are also available in an expandable table.

The dossier displays the selected detail response, evidence, quality/review flags, and in-service milestones. There is no Nemotron integration or generated planning brief. Equipment, labor, savings, and procurement feasibility are not invented. Records explicitly flagged `is_fixture` retain synthetic labels.

## Retained demo and legacy components

`lib/api.ts` and `lib/fixtures.ts` retain `getDemoData()` for explicit demo/testing use; the live page does not import it. The existing demo matching helpers, city renderer, and MapLibre components remain available. The bundled `public/city-osm.json` is a Miami OpenStreetMap extract (? OpenStreetMap contributors, [ODbL](https://www.openstreetmap.org/copyright)), used only by the retained demo rendering path. Live records are never snapped to those illustrative roads or associated with Miami buildings.
