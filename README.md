# Synchro

Turns utility construction plans into an explainable geospatial timeline and identifies potential cross-utility coordination opportunities.

## Team work

- [Badri](Badri/README.md): Dell source ingestion, evidence preservation, geometry candidates, and ASUS handoff files.
- [Tarun](Tarun/README.md): project intelligence, extraction, and validation.
- [Kevin](gridlock-control-plane/README.md): opportunity API and control plane.
- [SYNCHRO web](synchro-web/README.md): original React frontend with Motion animations, Location Workbench, qualified opportunities, and Decision Ledger views.
- [Integration path](integration/README.md): Dell-to-Mac conversion, accepted-version export to ASUS, and deployed API checks.

Each directory contains its own setup and integration notes.
